# 星云科技生产发布与回滚手册

版本：2.0

状态：待验证

适用范围：核心业务服务

## 1. 发布窗口

常规生产发布仅允许在周二、周四 20:00 至 23:00 执行。每周五 18:00 后进入变更冻结期，周末和法定节假日前最后一个工作日不安排非紧急发布。

紧急修复需要由研发负责人、运维负责人和技术总监共同批准，并至少提前 30 分钟通知值班人员。

## 2. 发布前检查

发布申请必须包含变更内容、影响范围、回滚方案、验证清单和负责人。缺少任一项时，运维有权拒绝发布。

新增要求：发布前必须完成依赖服务容量检查，并确认最近一次数据库恢复演练在 7 天内成功。

## 3. 发布过程

生产发布采用分批灰度。第一批流量不超过 2%，观察 15 分钟；第二批流量提升至 20%，观察 20 分钟；无异常后再全量发布。

如果错误率连续 3 分钟超过 0.5%，或 P95 延迟连续 5 分钟超过 1.5 秒，应立即暂停发布并评估回滚。

## 4. 回滚规则

P0 故障必须在 5 分钟内启动回滚决策，并在 15 分钟内完成应用回滚或流量切换。回滚完成后，负责人需要在事件群同步当前版本、数据状态和影响范围。

数据库结构变更优先采用向后兼容设计。所有补偿脚本必须先在预生产环境验证。

## 5. 备份策略

生产数据库每天 03:00 执行全量备份，备份文件保留 45 天。每周日 03:00 执行一次恢复演练，演练报告由数据库负责人和安全负责人共同确认。
