# 在线旅游法规知识基线（演示摘要）

> 本文为项目演示用的法规摘要，不是法律意见。法规内容以全国人大、中国政府网和文化和旅游部发布的正式文本为准。访问日期：2026-09-10。

## 2. 合同与行程信息

旅行社组织和安排旅游活动，应当与旅游者订立合同。包价旅游合同应当采用书面形式，并载明行程安排、交通住宿餐饮等服务标准和费用、违约责任、纠纷处理方式等事项。旅行社还应当在行程开始前提供旅游行程单。

知识库处理要求：

- 回答合同相关问题时，必须优先引用正式合同模板和当前有效版本。
- 涉及费用、退改、违约责任时，必须返回引用出处，不能只给模型总结。
- 行程单与合同版本不一致时，应提示人工核对，并保留两个版本。

## 3. 不可抗力与行程受影响

因不可抗力或者旅行社、履行辅助人已尽合理注意义务仍不能避免的事件影响行程时，法律规定了合同解除、变更、退款和安置等处理方式。合同解除的，组团社应当在扣除已向地接社或者履行辅助人支付且不可退还的费用后，将余款退还旅游者。

知识库处理要求：

- 遇到台风、地震、政府限制出行等事件，先确认订单状态、出发时间和实际损失。
- 不得直接把“不可抗力”解释为一定全额退款或一定不退。
- 回答必须提醒客服结合合同、供应商退改规则和实际不可退费用处理。

## 4. 信息展示与预订履行

在线旅游经营者应当提供真实、准确的旅游服务信息，不得虚假宣传；应建立公开、透明、可查询的预订渠道，促成预订服务依约履行。平台还应以显著方式区分自营业务和平台内经营者业务。

知识库处理要求：

- 回答中区分平台规则、供应商规则和目的地政策。
- 对变更频繁的航班、酒店和景区政策标注生效时间。
- 无法确认时返回低置信度，并引导人工确认。

## 5. 评价、算法和个人信息

在线旅游经营者应当保障旅游者的正当评价权。收集个人信息时，应事先说明目的、方式和范围，并取得同意。不得滥用大数据分析设置不公平交易条件。

知识库处理要求：

- 演示数据不得包含真实用户评价、手机号、证件号、订单号或聊天记录。
- 回答涉及个人信息时，只向有权限角色展示，并记录审计信息。
- 反馈数据用于质量优化时，应先脱敏和聚合。

## 6. 安全提示与救助

在线旅游经营者应对旅游者尽到安全提示和保障义务。因不可抗力或第三人造成旅游者损害时，应及时进行救助；未及时救助造成损害的，依法承担相应责任。

知识库处理要求：

- 客服遇到人身安全、滞留、重大交通中断时，优先转人工升级流程。
- RAG 回答只能作为处理建议，不得替代紧急救助和法定报告流程。
