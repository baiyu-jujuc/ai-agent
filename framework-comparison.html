上下文溢出

问题：对话历史无限增长
风险：超出模型上下文窗口

// 旧 - 仅限制消息数 while (history.size() > maxMessages) { history.pollFirst(); } // 40条长消息仍可能 > 32K tokens
Token 预算裁剪

方案：双重限制（消息数 + token）
估算：1 token ≈ 3.5 字符

// 新 - 消息数 + token 双重裁剪 while (history.size() > maxMessages) history.pollFirst(); int total = estimateTokens(history); while (total > maxTokens && history.size() > 2) { history.pollFirst(); total = estimateTokens(history); }
P2 安全防护 (CORS + 异常 + 限流 + API Key)
重构前（裸奔）
重构后（防护齐全）
无安全防护

问题：
1. 无全局异常处理 → 堆栈泄露
2. 无 CORS 配置 → 前端跨域被拒
3. 无限流 → 可被 DDoS
4. 无 API Key → 任何人可调用
5. H2 控制台开启 → 数据库暴露
6. 文件工具无路径校验 → 任意文件读写
7. HTTP 工具无 SSRF 防护 → 内网探测

// 文件工具 - 旧（无校验） Path path = Path.of(input); Files.readString(path); // 可读取 /etc/passwd 等系统文件
SecurityConfig GlobalExceptionHandler

修复：
1. GlobalExceptionHandler - 4类异常处理
2. CORS - 允许跨域 + 凭证
3. RateLimitInterceptor - 30 req/min/IP
4. ApiKeyInterceptor - X-API-Key 校验
5. H2 控制台默认关闭
6. 文件工具沙箱（Path.normalize + startsWith）
7. HTTP 工具 SSRF 黑名单（内网/元数据）

// 文件工具 - 新（沙箱） Path baseDir = Path.of(allowedBaseDir) .toAbsolutePath().normalize(); Path resolved = baseDir.resolve(input).normalize(); if (!resolved.startsWith(baseDir)) throw new SecurityException("路径越权");
